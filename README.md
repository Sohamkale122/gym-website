# 💪 Jerai Fitness - Premium Gym Website

A modern, responsive gym website built with **React**, **Tailwind CSS v4**, and **Vite**. Features stunning UI/UX with smooth animations, glass-morphism design, and a dark theme aesthetic.

![React](https://img.shields.io/badge/React-18-blue?style=flat-square&logo=react)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-v4-38bdf8?style=flat-square&logo=tailwindcss)
![Vite](https://img.shields.io/badge/Vite-Latest-646cff?style=flat-square&logo=vite)

## ✨ Features

- 🎨 **Stunning Dark UI** - Modern glass-morphism design with orange/red gradient accents
- 📱 **Fully Responsive** - Looks great on all devices (mobile, tablet, desktop)
- ⚡ **Fast Performance** - Built with Vite for lightning-fast dev & builds
- 🏋️ **Workout Programs** - Showcase of 6 different workout programs
- 💰 **Membership Plans** - Interactive pricing with monthly/yearly toggle
- 👥 **Trainer Profiles** - Meet the expert trainers section
- 📊 **BMI Calculator** - Interactive BMI calculator with visual feedback
- 💬 **Testimonials** - Auto-rotating testimonial carousel
- 📧 **Contact Form** - Beautiful contact form with validation
- 🔝 **Scroll-to-Top** - Smooth scroll navigation
- ✨ **Animations** - Intersection Observer-based scroll animations

## 🚀 Tech Stack

- **React 18** - Component-based UI library
- **Tailwind CSS v4** - Utility-first CSS framework
- **Vite** - Next-gen build tool
- **React Icons** - Popular icon library
- **React Scroll** - Smooth scrolling navigation

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/Sohamkale122/gym-website.git

# Navigate to the project
cd gym-website

# Install dependencies
npm install

# Start dev server
npm run dev
```

## 🏗️ Build

```bash
npm run build
```
